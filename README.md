# Absurd Invention Pitch (One Sentence)

A one-sentence pitch for a fictional absurd invention: the Meeting Muter,
a small device that ends meetings with a loud foghorn the moment someone
says "let's circle back".

Running `main.py` writes the entry line to `/output/entry.txt`.
